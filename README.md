# rakit

*rakit* (Indonesian: "to assemble") — a Go agent engine for coding tasks, and the
`rakit` CLI that drives it. One brain, many surfaces: embed the engine as a Go
library, or use the CLI in your terminal like any other coding agent.

> Work in progress — engine packages are being extracted from
> [forge-ade](https://github.com/hasdev/forge-ade). This README grows as
> batches land.

## Install (once published)

```sh
go install github.com/Haslab-dev/RakitKode/cmd/rakit@latest
```
